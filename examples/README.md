# README

These are all simple single-file executables to demonstrate the use of the `xoshiro` library.
Most of them depend on our [`utilities`][] library, which has a handy stopwatch class, etc.

The examples in this directory that are prefixed `gf2-` also use the [`gf2`][] library.
